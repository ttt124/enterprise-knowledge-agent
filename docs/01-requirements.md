# 需求说明

## 目标与交付范围

本次提交提供一个可在本机运行的企业知识问答 Agent 演示：接收自然语言问题，由模型选择检索工具，读取本地知识资料，再结合证据回答。项目范围包括工具调用过程、证据约束和异常处理，暂未覆盖企业级检索规模或生产部署。

交付物包括 Python 命令行程序、自拟知识库、自动化测试、评测脚本、运行记录及设计文档，未收录保密题目原文。

## 功能需求

| 编号 | 需求 | 可观察的验收依据 |
| --- | --- | --- |
| R01 | 模型自主选择 `search_documents` 与 `read_document`，工具结果返回模型后继续推理 | 实时模式的 trace 显示模型请求、工具执行结果与最终输出 |
| R02 | 回答受本地资料约束，并提供可追溯的引用 | 文档 ID 可定位；引用原文可逐字核验 |
| R03 | 资料不足时说明缺口，避免补造制度 | 库外问题或必要信息缺失用例的输出 |
| R04 | 识别同主题资料冲突，不擅自指定优先级 | 报销期限冲突用例同时保留两个来源并说明无法裁定 |
| R05 | 支持基于历史消息的追问 | 含历史消息的输入与工具轨迹 |
| R06 | 工具失败与调用次数受控 | 注入失败、达到工具上限时有可解释结果，不无限循环 |
| R07 | 支持复现实验 | 保存输入、输出、轨迹、资料快照和汇总 |

## 自拟知识库

## 运行边界与验收方法

- Python 标准库实现，无第三方运行依赖。实时模式通过 HTTP 调用兼容 Chat Completions 的模型接口；需要用户本机配置有效凭据与服务参数。
- 模拟模式只验证离线程序流程和预设场景，不能证明真实模型的检索、理解或回答效果。
- 默认工具调用上限为 8、模型轮数上限为 12，命令参数见 README。
- 小型关键词检索用于演示，可召回同主题多个候选；不承诺大规模语料检索能力、权限隔离、持久记忆、生产可靠性或业务效果。

用例 T01–T09 覆盖正常检索、证据不足、冲突、多轮追问、工具失败与次数约束，并通过修改事实、新增冲突检查实现是否依赖原始答案。实际输入、判定规则、通过情况见 `03-evaluation.md` 与运行产物；通过固定用例不等于覆盖全部真实问题。
