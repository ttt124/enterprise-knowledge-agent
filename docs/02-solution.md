# 方案设计

## 实现思路

采用“模型决定下一步、本地工具提供证据”的工具循环。Python 标准库承担配置读取、JSON、HTTP 请求和命令行处理，无第三方安装依赖；本次验证环境为 Python 3.13.14，实时模型为 `deepseek-flash`，API 返回的模型名同为 `deepseek-flash`。知识资料保存在本地 JSON 中，便于检查与变更实验。

实时运行链路：

```text
问题与可选历史消息
  → 模型接收系统约束、消息和工具定义
  → 模型请求 search_documents / read_document
  → 本地执行工具，记录调用与结果
  → 工具结果追加到消息，返回模型
  → 模型继续调用工具或提交最终回答
  → 校验引用并保存输出、轨迹
```

模型提出调用请求，本地代码负责识别工具、校验参数、执行检索、控制预算与记录异常。实时 trace 保存工具调用、返回结果和后续动作，作为模型使用工具及调整动作的核验依据。

## 模块职责

| 模块 | 职责 |
| --- | --- |
| `config.py` | 加载接口、模型和运行配置 |
| `model.py` | 使用 `urllib` 调用兼容 Chat Completions 的接口 |
| `agent.py` | 维护消息循环、执行模型工具请求、处理上限与校验引用 |
| `mock.py` | 明确标记的离线模拟模型，用于流程验证 |
| `cli.py`、`run.py` | 接收问题、历史消息、模式、故障注入与产物输出参数 |
| `tools.py` | 加载文档，实现搜索与按 ID 读取 |
| `scripts/evaluate.py` | 批量运行用例，保存快照、轨迹与汇总 |

参数说明与执行命令见 README，模块位于 `src/knowledge_agent`。

## 两个本地工具

`search_documents` 接收查询词，返回候选文档及检索线索。它结合关键词、同义词和中文相邻双字片段进行匹配，并召回同主题候选，降低小型演示库中遗漏冲突资料的概率。相关性分数只表示本地匹配强度，不能当作制度权威性或答案置信度。

`read_document` 按文档 ID 返回完整内容。搜索负责发现资料，读取负责提供可引用证据；最终答案应基于实际读取结果，而不是搜索词或模型已有知识。

这种方法适合六份短文档，便于审阅和定位故障。语料扩展后需要另行评估切分、全文或向量检索、召回排序、权限过滤和版本管理；这些属于后续扩展范围。

## 证据与冲突处理

回答应标注文档 ID 并引用原文。程序对引用做逐字校验，确认引用来自已提供的资料。该校验能发现伪造或改写的引文，但不能完整证明回答逻辑正确、资料已召回齐全或结论覆盖所有适用条件；这些仍需评测与人工核对。

对于 D002 的 30 个自然日与 D003 的 15 个自然日，资料没有确定优先级，因此应列出两条规则及来源，说明冲突并建议向制度负责人确认。资料日期不等于明确的替代关系；不得自行按日期、文档编号、检索排名或措辞推定生效顺序。

对于资料未覆盖的问题，回答说明未找到依据。多轮追问使用传入历史消息解析指代，制度结论仍以本次读取的资料为依据；本项目未实现跨会话持久记忆。

## 故障控制与可观测性

默认工具调用上限为 8、模型轮数上限为 12。失败调用也消耗工具预算。工具错误通过工具结果返回模型，允许模型在剩余预算内恢复。恰好用完工具预算后，在剩余模型轮数内允许一次无工具收尾，让模型使用已取得的证据；若仍请求工具或结果校验失败，则返回 `incomplete`，不额外执行工具。

离线与实时产物分目录保存，每例包含 `input.json`、`output.json`、`trace.json`、`documents.json`，批次另有 `summary.json` 与 `report.md`。资料快照用于解释当次回答，并支持修改事实、新增冲突后的回归比较。HTTP 客户端拒绝重定向，避免鉴权头被默认跳转行为转发；该行为已用假密钥和本地 302 响应测试。输出不记录请求鉴权头和服务端错误原文，本机 `.env` 不应纳入提交。

## 验证结果与边界

最终[实时评测](../examples/live/run-20261107T131207894281Z/report.md)的 9 个用例通过业务与证据断言，28 项单元测试通过；[模拟评测](../examples/mock/run-20261107T130716791849Z/report.md)的 9 个用例仅通过离线流程断言，不代表模型效果。完整记录见 `03-evaluation.md`。

第一次实时运行曾出现自动检查未识别的越界建议与未读摘要转述，修订后保留旧输出与复核失败记录。提示约束、逐字引用和正则断言均不是通用语义证明。复杂指代、其他冲突措辞、更大语料、长文、权限隔离及模型服务变化未由本次固定用例充分验证。
